# yamulla — сайт-визитка

Личный сайт-визитка frontend-разработчика. Тёмная hacker/terminal тема с
переключателем на светлую, адаптив под телефон/планшет/десктоп.

## Стек

Чистый HTML / CSS / JS, без сборки и зависимостей — можно деплоить как
статический сайт.

## Запуск локально

Просто открой `index.html` в браузере, либо подними локальный статический
сервер, например:

```bash
npx serve .
```

## Деплой на Vercel

```bash
npx vercel --prod
```
